# Flow3D Studio Skill

## System Overview
Flow3D Studio provides full procedural 3D design, interactive WebGL visualization, and parametric CAD synthesis directly within the Flowork OS ecosystem. It connects directly with the sovereign 34,840-model vault across 7 modalities:
- Three.js WebGL scenes (1,188 interactive single-file environments)
- CadQuery OpenCASCADE Python assemblies (2,306 precision mechanical parts)
- OpenSCAD CSG parametric solids (2,386 3D-printable models)
- Bioinspired Blender BPY structures (4,557 organic and architectural forms)
- Blender Infinigen procedural geometry & PBR shaders (486 Hollywood-grade assets)
- DeepCAD sequence tokens (26,444 neural CAD engineering sequences)

## Key Capabilities
1. **Interactive WebGL Canvas**:
   - OrbitControls, grid floor, axes helper, real-time lighting rigs, ACES filmic tone mapping, and wireframe toggle.
   - Live execution and hot-reloading of procedural Three.js JavaScript/HTML scenes.
2. **Procedural Asset Vault Browser**:
   - High-speed pagination, real-time search, and modality filtering across all 34,840 assets.
   - Comprehensive metadata viewer with source code inspection, generation recipes, and style annotations.
3. **AI Prompt-to-3D Synthesis**:
   - Few-shot semantic generator leveraging local parametric examples to craft valid procedural 3D geometry.
4. **Turntable Video Studio**:
   - High-fidelity 360° turntable video rendering using FFmpeg.
   - Preset aspect ratios: 16:9 Landscape for YouTube long-form, 9:16 Vertical for YouTube Shorts, Reels, and TikTok.
   - Native OS folder picker integration for direct output directory selection.
5. **Multi-Format Export**:
   - One-click exports to STL, STEP, GLB, and standalone interactive HTML bundles.
