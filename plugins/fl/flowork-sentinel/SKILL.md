# FLOWORK SENTINEL & SKILL SYNTHESIZER

## 1. Overview
Flowork Sentinel captures human interactions and backend network API calls across external web applications (Suno, Facebook, Canva, SaaS tools). It reconstructs user intent into an ordered procedural workflow and outputs a production-ready `SKILL.md` and executable Puppeteer automation script.

## 2. Operational Procedures
1. Ensure the Sentinel Engine is running on `http://127.0.0.1:17870`.
2. Activate the Flowork Sentinel extension in Chrome/Brave/Edge.
3. Perform the desired task once on the target web application.
4. Stop the recording to save the raw event stream.
5. In Sentinel Studio, click **Synthesize to SKILL.md** to extract steps and network APIs.
6. Click **Deploy to Flowork Skills** to register the new skill for autonomous agents.
