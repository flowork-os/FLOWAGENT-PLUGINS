Challenge

Games are easier to make than you think

Modern LLMs write the whole thing — mechanics, art, controls. The hard part used to be everything after: hosting, links, players. That part is one command through the Playgama MCP: your agent publishes to a sandbox and you get a public playable URL to share — and the first real numbers on how people actually play it.

How it works → https://playgama.com/mcp/

Build games with AI agents

Models like GPT-6 Astra and Fable turned agent-built games from a demo into a wave — new titles all over Reddit and X, plenty of them from people who have never written a line of code. What has been missing is somewhere to put them.

Connect your Playgama account once. Then ask your agent to upload your game and return a public playable link. Every game needs the Playgama Bridge SDK, the sandbox included — your agent reads its docs and integrates it before the upload. The workflow and the service both run on MCP, the open protocol that Codex, Claude Code and whatever else you have open already use to reach external tools.

For humans

Upload this game to Playgama and give me a public playable link. If the game does not have the Playgama Bridge SDK yet, integrate it first — Playgama requires it for every game. Follow the agent setup instructions at https://playgama.com/mcp/. If my account is not connected, guide me through the one-time setup, then continue with the upload.
Read the guideAgent instructions (md)

For AI agents

To upload a game, first read https://wiki.playgama.com/playgama/mcp.md. It contains client setup, sign-in, upload and sandbox publishing instructions.

If Playgama tools are already connected, verify access and continue. Otherwise, guide the user through adding https://developer.playgama.com/api/mcp to their MCP client and signing in to Playgama in the browser it opens. Never ask for their password in chat. Connected agents are managed at https://developer.playgama.com/mcp.

The Playgama Bridge SDK is required for every game on Playgama, the sandbox included. If the game does not have it yet, integrate it before you upload — the get_bridge_sdk_docs tool and the Bridge SDK guide have the integration docs. Never publish a build in which the SDK was not detected.

For this workflow, return a public sandbox URL. Main catalog submission is a separate step.
